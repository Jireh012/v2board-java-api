# 充值奖励生效与用户充值

## Goal

修复充值奖励未读取嵌套配置的问题；补齐用户端钱包充值下单入口，使管理端规则在支付开通后真正加赠。

## Requirements

1. `getBonus` 从 `deposit.deposit_bounus` 读取规则；元→分；取满足门槛的最大赠送额。  
2. type=9 且 `total_amount>0` 的充值订单开通时加赠；佣金划转（amount=0）不加赠。  
3. 用户端个人中心「立即充值」可输入金额（元）→ 创建 deposit 订单 → 进入支付/订单详情。  
4. 键名保持 PHP 拼写 `deposit_bounus`。

## Acceptance Criteria

| ID | Criterion |
|----|-----------|
| AC1 | 规则 `100:10`，充值 100 元开通后余额 +110 元（本金+赠送） |
| AC2 | 未配置或金额未达门槛 → 仅到账本金 |
| AC3 | 个人中心可完成创建充值订单并跳转结账 |
| AC4 | 佣金划转不触发赠送 |

## Out of Scope

- 预览预计赠送金额的复杂阶梯 UI（可选简单提示）  
- 管理端改键名
